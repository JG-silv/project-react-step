# 🧠 Conceitos de React Aplicados

## ⚛️ Componentes

A aplicação foi estruturada utilizando componentes React, permitindo dividir a interface em partes menores, organizadas e reutilizáveis.

---

## 🧩 Props

Uso de `props` para realizar a comunicação entre componentes e permitir a passagem de informações entre diferentes partes da aplicação.

```jsx
<Component data={data} />
```

---

## 🪝 Hooks

Utilização dos Hooks do React para trabalhar com comportamento, estado e ciclo de vida dos componentes.

Exemplo:

```jsx
const [value, setValue] = useState("");
```

---

## 🔁 Renderização de Arrays

Uso de métodos do JavaScript, como:

```javascript
array.map()
```

para gerar elementos dinamicamente dentro da interface.

---

## 🔀 Renderização Condicional

Exibição de diferentes elementos da interface de acordo com o estado e as condições da aplicação.

```jsx
{isLoggedIn ? <Dashboard /> : <Login />}
```

---

## 🌐 Requisições HTTP

Aplicação dos conceitos estudados sobre comunicação com recursos externos através de requisições HTTP.

---

## 📝 Formulários

Criação e gerenciamento de formulários utilizando React, incluindo:

* Captura de valores;
* Eventos;
* Inputs controlados;
* Atualização de estado;
* Submissão de dados.

---

## 🧭 Roteamento

Implementação da navegação entre diferentes páginas da aplicação utilizando os conceitos de roteamento estudados durante o curso.

Uma das rotas disponíveis no projeto publicado é:

```text

```

# ⚙️ Executando o Projeto Localmente

## 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO.git
```

---

## 2. Entre na pasta do projeto

```bash
cd curso-react-step
```

---

## 3. Acesse a branch do projeto final

```bash
git switch projeto-final
```

Caso esteja utilizando uma versão mais antiga do Git:

```bash
git checkout projeto-final
```

---

## 4. Instale as dependências

```bash
npm install
```

---

## 5. Execute o projeto

```bash
npm run dev
```

---

## 6. Abra no navegador

O Vite normalmente disponibilizará a aplicação em:

```text
http://localhost:5173
```
